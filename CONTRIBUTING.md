# Contributing

Contributions are welcome and will be fully credited.

We accept contributions via Pull Requests on GitHub:
- https://github.com/HellFiveOsborn/router

## Pull Requests

- Coding Standard: PSR-12 (the successor of PSR-2). You can use PHP-CS-Fixer or PHP_CodeSniffer.
- Document behaviour changes: Keep [README.md](README.md:1) and docs updated.
- Create topic branches: Don’t open PRs from your main/master branch.
- One PR per feature/fix: Separate unrelated changes.
- Clean history: Rebase or squash before submitting to keep commits meaningful.
